# New Heritage

Interactive group project for the New Heritage capital allocation case.

Website: https://praymo.github.io/nh/

This repository publishes its `main` branch root through GitHub Pages.
No installation or build step is required. Open `index.html` to view offline.

The original deployment HTML is preserved byte for byte from
`New_Heritage_FINAL_20261029.zip`; its checksum is recorded in `RELEASE.json`.
Netlify configuration files are retained for portability. GitHub Pages does
not apply Netlify-specific cache headers.
